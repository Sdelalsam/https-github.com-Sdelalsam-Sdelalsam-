Телеграмм бот: @Practical12Bot.
При запуске бота появляется приветсие: "Добро пожаловать в квиз!".
Посл выбора кнопки бот начинает игру и предлагает ответить на вопросы. 
При нерпавильном ответе бот предлагает отвтеить на вопрос правильно.
После окончания игры бот выводит информацию о колличестве ответов правильных и неправильных.
